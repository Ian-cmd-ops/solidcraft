## Mistakes and lessons

- I switched a branch in a worktree while a golden run used it. I stopped the run before it tested the wrong code. Use a separate worktree for long runs.
- The container restarts without notice and kills background runs. Check the log, not the process.
- The shared target directory with several worktrees can give linker errors. Clean the kernel package and the incremental folders.
- A cloned `origin/main` goes stale. The stop hook counts commits against it and warns about unpushed work that is already pushed.
- On the cloud box, `cargo xtask ci` fails clippy in `ui-egui` (Rust 1.97, `manual_option_zip`). The wasm target cannot download here. Run both on the laptop.
- GitHub list pages are blocked for WebFetch. Single issue pages work. `gh` on the laptop works.
